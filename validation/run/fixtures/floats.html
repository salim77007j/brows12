Rust is a multi-paradigm, general-purpose programming language that emphasizes performance, type safety, and concurrency. It enforces memory safety without a garbage collector by means of an ownership system where each value has a unique owner.

The compiler checks these ownership rules statically and refuses programs that would create dangling pointers or data races. This design allows predictable, low-latency performance comparable to C and C++ while preventing entire classes of memory bugs at compile time.
