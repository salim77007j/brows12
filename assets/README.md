# assets

- `icon.png` — 256×256 application icon, rendered by the brows12 engine's
  own pipeline (`brows render --html validation/run/icon.html --png
  assets/icon.png`) from `validation/run/icon.html`: HTML + CSS in, pixels
  out, no image editor involved.

Browser UI screenshots live in [`/screenshots`](../screenshots) (produced by
`validation/run_validation.sh`, described in
[`validation/MINIMAL_UI_REPORT.md`](../validation/MINIMAL_UI_REPORT.md)).
